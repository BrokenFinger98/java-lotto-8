# 구현 기능 목록

## 구입 금액 입력

- 로또 구입 금액을 입력 받는다.
- 금액은 1,000원 단위이며, 1,000원으로 나누어 떻어지지 않으면 예외 발생
    - 예: 8,500원 입력 시 -> [ERROR] 구입 금액은 1,000원 단위여야 합니다.

## 로또 발생

- 로또 1장의 가격은 1,000원이다.
- 구입 금액만큼 로또를 발행한다.
- 1개의 로또는 1~45 사이의 중복되지 않은 6개의 숫자로 구성된다.
- 발행한 로또는 오름차순 정렬되어 출력된다.

## 당첨 번호 입력

- 쉼표(,)로 구분된 6개의 숫자를 입력받는다.
- 보너스 번호를 한 개 입력받는다.
- 중복된 숫자 또는 1~45 범위를 벗어나면 예외 발생
    - 예: [ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.

## 당첨 결과 계산

- 구매한 모든 로또를 당첨 번호와 비교한다.
- 당첨 기준에 따라 1~5등을 판정한다.

| 순위 | 조건                 | 상금             |
|----|--------------------|----------------|
| 1등 | 6개 번호 일치           | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치  | 30,000,000원    |
| 3등 | 5개 번호 일치           | 1,500,000원     |
| 4등 | 4개 번호 일치           | 50,000원        |
| 5등 | 3개 번호 일치           | 5,000원         |

## 수익률 계산 및 출력

- 당첨 내역을 순위별로 출력한다.
- 총 당첨 금액을 계산하고, 구입 금액 대비 **수익률(%)**을 소수점 둘째 자리에서 반올림하여 출력한다.

## 예외 상황 처리

- 잘못된 입력 시 IllegalArgumentException을 발생시키고 [ERROR]로 시작하는 메시지를 출력한다. 
- 에러 발생 시 해당 단계부터 입력을 다시 받는다.
- Exception이 아닌 IllegalArgumentException, IllegalStateException 등과 같은 명확한 유형을 처리한다.

|구분| 조건| 예외 메시지|
|---|---|---|
|금액| 1000원 단위가 아닐 때 |[ERROR] 구입 금액은 1,000원 단위여야 합니다.|
|번호 입력|숫자 개수가 6개가 아닐 때|[ERROR] 로또 번호는 6개여야 합니다.|
|번호 입력|범위(1~45) 벗어날 때|[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.|
|번호 입력|중복된 숫자가 있을 때|[ERROR] 로또 번호는 중복될 수 없습니다.|
|보너스|당첨 번호와 중복일 때|[ERROR] 보너스 번호는 당첨 번호와 중복될 수 없습니다.|
